# Rayan Chowdhury Ridi — Personal Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript. It includes a home page, about section, skills, project showcase, education timeline, achievements area, and contact section.

## Files
- `index.html` — content and structure
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu, active navigation, and current year
- `assets/ridi-profile.jpg` — profile photo supplied for this portfolio

## Preview
Open `index.html` in a browser, or use VS Code with Live Server.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and click **Save**.
5. Wait for the deployment, then use the published link shown on the Pages settings page.

## Before submitting
- Replace education placeholders with accurate school/college/university details.
- Replace the suggested project ideas with real work, and link to repositories or demos.
- Add only genuine achievements, certificates, and awards.
- Replace `your.email@example.com` and the GitHub/LinkedIn placeholder links in `index.html`.
- Review the site and personalize it so it accurately represents Ridi.

The project cards are ideas for future work, not claims that these projects have already been completed.
